# IRCPilot

A modern, privacy-first IRC server built in Rust. E2E encryption, anonymity, bidirectional ignore, and immutable moderation rules. Open source, non-commercial, community-driven.

## Project brand

IRCPilot uses a peacock pilot emblem to represent identity, visibility, freedom, and controlled flight through a hostile network.

![IRCPilot logo](assets/ircpilot-logo.svg)

## Core design

IRCPilot is not just a server; it is a system with a strong client layer and a rich protocol. The protocol is designed for:

- privacy-first channels and identity
- multiple transport streams
- live UI panels for games, media, polls, and chat
- modular interaction without breaking the IRC conversation model
- future extensibility without losing the classic IRC spirit
